# 要件

## 1. 目的

Dropbox API を使った**閲覧専用**の Android アプリ。画面は Dropbox 公式モバイルアプリの「写真」タブにほぼ準拠する。公式との違いは、表示対象のフォルダを指定でき、サブフォルダを探索するかどうかも指定できること。

- 利用者: 自分(斎藤)の個人 Dropbox アカウント。Play ストア公開は想定しない
- 主な対象フォルダ: `/愛実ちゃん写真`(サブフォルダ含む)。他に `HDR-AS300` などに切り替えることもある

## 2. 当初の要件(2026-11-03)

| # | 要件 | 状態 |
|---|---|---|
| R1 | 閲覧専用(変更・削除はしない)。Dropbox の権限も読み取りのみ | 実装済 |
| R2 | 表示対象フォルダを指定できる(Dropbox のフォルダ階層をたどって選ぶ) | 実装済 |
| R3 | 指定フォルダのサブフォルダを探索するか ON/OFF できる | 実装済 |
| R4 | 公式「写真」タブ風のグリッド。撮影日時の新しい順 | 実装済 |
| R5 | 日付でグループ化(日・月・年)して見出しを出す | 実装済 |
| R6 | タップで1枚表示。左右スワイプ、ピンチズーム。動画は外部プレーヤーで再生 | 実装済 |
| R7 | 公式と同じく 15KB 未満の画像と PNG を除外(設定で OFF 可) | 実装済 |
| R8 | 写真のみ/動画のみ/すべて の絞り込み | 実装済 |

公式「写真」タブの仕様(調査結果):
- 撮影日時(EXIF)で並べ、無い場合は最終更新日時で並べる
- 15KB 未満または .png は除外
- 年・月・日でグループ化、スター付き絞り込み(スターは API で扱えないため本アプリでは対象外)

## 4. 未決事項・候補(次回以降)

- 公式 Web と月ごとの件数が合わない件の調査(2026年9月: アプリ 22 件、Web 10 件)→ debug.md D9
- Wi-Fi 接続時に全サムネイルを先読みするか(現状は最新100件のみ)
- キャッシュ上限(グリッド200MB/ビューア100MB)を設定画面で変えられるようにするか
- 2列表示(大きいサムネイル)に対応するか。対応するなら 256px より大きいサムネイルを取る必要がある
- 裏での撮影日時取得を止める選択肢を設けるか(止めると古い写真は更新日時で並ぶ)
- 複数フォルダの指定、動画のアプリ内再生、地図表示、認証情報の暗号化(DESIGN.md 11章の拡張候補)
- HEIC 写真と動画のサムネイルが取れるかの確認(API の公式対応形式に含まれない)
