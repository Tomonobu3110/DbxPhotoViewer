# 作業履歴

## 2026-11-04

ビューアに「スライドショー」機能を追加(R17〜R23)。

1. ビューアのツールバーに「スライドショー開始」を追加し、`SlideshowActivity` を新設。表示中の写真から過去方向へ最大60枚を1枚30秒で自動再生(静止画は表示、動画は無音・ループ)
2. 実機確認しながら修正:
   - メニュー項目が見つからない(`showAsAction="never"` でオーバーフロー「…」の中に隠れていた)→ 一度 `always|withText` でツールバーに直接表示する形に変更したが、ユーザーの希望で再度オーバーフローに戻し、`popupTheme` を明示してドロップダウンの文字を見やすくした(D12)
   - 動画がくるくるのままで再生されない → `VideoView` を `visibility=GONE` のまま `setVideoURI` していたため、内部の `SurfaceView` が生成されず `onPrepared` が呼ばれなかった(D10)
   - 動画の再生位置が画面中央でない → `VideoView` は動画のアスペクト比に合わせて自身のサイズを縮めるため、`FrameLayout` のデフォルト(左上寄せ)配置になっていた。`layout_gravity="center"` を追加(D11)
3. 進捗表示(経過枚数)と「スライドショーの停止」ボタンを、10秒操作がないと下へスライドアウトして隠す/画面タップで下からスライドインして復帰するように変更(R21)
4. 静止画→静止画の遷移をクロスフェード(ImageView 2枚重ね+alpha アニメーション)に変更。動画が絡む遷移は即切り替えのまま(R22)
5. 60枚再生し終えたら停止する代わりに、Dropbox を同期(`SyncManager.requestSync()`)→ 同期完了を待って DB から最新順一覧を再取得 → 最新の写真・動画を起点にまた60枚、という無限ループに変更(R23)。停止時にビューアへ返す情報を一覧の位置から写真・動画の ID に変更し、ループで一覧の並びが変わってもズレずに戻れるようにした
6. このドキュメント群(requirements.md、debug.md、implementation-notes.md、DESIGN.md、本ファイル)を更新
